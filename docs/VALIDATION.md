- Blender в рамках этого изменения не запускался. Обработка area-света в импорте обновлена, Cycles требует отдельной проверки.

Следующий прогон на обычном локальном сервере:

```sh
npm run dev
npm run test:e2e
# Когда будет настроен Blender:
npm run test:e2e -- --blender
```

Визуально проверить все четыре сценария при одинаковом ракурсе, особенно отсутствие выбеливания в «Основном» и читаемость предметов ночью. Автоматический smoke проверяет отсутствие полей редактирования, переключение камер/света без изменения модели, GLB round trip и PNG. Код и успешная сборка сами по себе не подтверждают качество изображения.

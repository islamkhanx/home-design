# Home Design

Локальный параметрический просмотр квартиры: Vue 3 + TresJS / Three.js для FAST, GLB → Blender Cycles для PERFECT. Один JSON, одна геометрия, два способа показа.

**Модель редактируется в исходном JSON/TypeScript.** В интерфейсе доступны прогулка по комнатам, размеры, свет, фотореалистичные кадры, отдельные варианты отделки, видеотур и документы. Результаты проверок приложения и отдельных дизайн-исследований: см. [протокол](docs/VALIDATION.md).

Проверка расстановки и геометрии: `npm run review:geometry`. Регрессии и намеренно
сломанные примеры: `npm run test:review`. Алгоритмы проверяют реальные части
канонической сцены; правила текущей квартиры заданы отдельным профилем.
[Область проверки, отчёт и добавление новых правил](docs/GEOMETRY_REVIEW.md).

## Контекст и выбранный дизайн

[Общий контекст проекта](docs/PROJECT_CONTEXT.md) · [Спецификация санузла](docs/bathroom-spec.json) · [Галерея схем и рендеров](design/README.md).

Текущий выбор: **A3 / M1 / T1 / У1 / Д2**, ванна, подвесная сантехника и электрический полотенцесушитель. Ночная подсветка исключена. Интерактивная модель синхронизирована по A3 / M1 / T1 / Д2. Деталировка У1 и размещение полотенцесушителя остаются открытыми; актуальность определяется спецификацией.

## Запуск

Нужны Node.js 22.16+, npm, браузер с WebGL2. Для PERFECT — установленный Blender с Cycles (целевые версии 4.5 LTS / 5.x; фактическая совместимость проверяется полным тестом).

```sh
cd home-design
npm install
npm run dev
```

Открыть `http://127.0.0.1:5173`. Для CLI-экспорта используется установленный Google Chrome на macOS либо Chromium Playwright:

```sh
npx playwright install chromium
cp .env.example .env
npm run doctor
```

В `.env` можно задать `BLENDER_PATH`, `CYCLES_DEVICE=auto|cpu|gpu`, `CHROME_PATH`. Для стандартной установки Blender на macOS путь находится автоматически. `gpu` требует рабочий GPU; `auto` пробует GPU и допускает переход на CPU.

## Просмотр дизайна

- Вся квартира и шесть помещений по оцифрованному исходному плану. «Общий вид», «Внутри» выбранной комнаты, «План», «Электрика» и «Потолки»; мышью можно вращать, приближать и перемещать камеру.
- «Электрика»: 18 розеточных блоков / 30 гнёзд и 5 выключателей, с обозначениями и высотами. «Потолки»: вид снизу с освещением; отметка 2850 мм — предложение. [Схемы и рендеры ревизии 7](design/electrical-ceilings-v01/README.md).
- Размеры включаются отдельно; по умолчанию подписи не перекрывают интерьер.
- «Материалы» — нейтральный обзорный свет. «Основной» — основные приборы; «Вечер» — локальные светильники. В санузле сохранены предложения G1/G2 и вечер только у зеркала. Ночной сценарий исключён.
- Световые потоки в модели сохранены; яркость FAST нормализована для показа на экране. Это не расчёт lux.
- Фактура дерева и камня имеет метрический масштаб, карты шероховатости и микрорельефа. Текстуры — условные образцы, не каталожная отделка.
- Нет редактора геометрии, дерева объектов или добавления/удаления предметов. Старый localStorage редактора не читается и не перезаписывается.

Для автономного HTML, который можно открыть без dev-сервера:

```sh
npm run preview:offline
```

Открыть `.artifacts/offline/home-design-preview.html` обычным браузером. Скрипт включает приложение, стили и процедурные материалы в один файл. При использовании собственных файловых текстур автономную упаковку нужно дополнить ими.

## CLI: экспорт и финальные изображения

```sh
npm run export:scene
npm run render:preview
npm run render:quality
npm run render:ultra

# Своя версия исходного JSON:
npm run export:scene -- --input /absolute/path/apartment.json --view plan
npm run render:quality -- --input /absolute/path/apartment.json --view interior --device cpu
```

`export:scene` запускает собственный временный Vite и headless-браузер, использует **тот же** экспортер, сохраняет `exports/latest/{scene.glb,scene.metadata.json,apartment.json,fast.png}`. `render:*` по умолчанию делает свежий экспорт, затем рендерит в `exports/<preset>/render.png`. `--reuse` явно разрешает использовать уже существующий экспорт в соответствующем каталоге. CLI не читает localStorage вашего обычного браузера.

| Preset  |       PNG | Максимум samples | Adaptive threshold |
| ------- | --------: | ---------------: | -----------------: |
| draft   |   480×270 |               16 |               0.12 |
| preview |   960×540 |               32 |               0.08 |
| quality | 1920×1080 |              256 |               0.02 |
| ultra   | 3840×2160 |             1024 |              0.008 |

Все режимы используют denoising. Время зависит от сцены и компьютера. Проверка `geometry-validation.json` должна пройти до рендера; `render-report.json` фиксирует устройство, preset и исходную ревизию.

Blender запускается через CLI или локальные панели приложения. `npm run build` создаёт статический FAST-просмотр; `npm run preview` не запускает процессы Blender. Генерация доступна через `npm run dev`. Сервер не требует аккаунта, не отправляет сцену в облако, не принимает произвольные команды или пути выполнения. Переданная GLB должна содержать текстуры и буферы внутри файла.

### Фотореалистичный кадр из прогулки

Выберите комнату → «Внутри», пройдите к нужной точке (WASD, мышь для обзора),
затем нажмите «Создать фотореалистичный кадр» в боковой панели. Рендер берёт
текущий ракурс и полную геометрию квартиры, включая стены и потолки. После
завершения переключатель «Фотореализм» показывает сохранённый снимок;
«Прогулка 3D» возвращает интерактивное управление. Есть прогресс, отмена и PNG.

В меню «Свет» на сцене общий выключатель «Свет из окон» управляет дневным
светом, а ниже можно включать отдельные окна и светильники по комнатам.
Общий выключатель запоминает выбор окон. Кнопка «Сбросить к сценарию»
возвращает настройки текущего сценария. Cycles берёт состояние источников
в момент запуска кадра вместе с ракурсом.

Фото-профиль использует дневной свет через положения окон, установленные
светильники, отражённый свет Cycles, AgX, микрофактуру тканей/краски и шейдерные
фаски. Геометрия не меняется. Это приближение архитектурной фотографии,
не фотометрический расчёт; упрощение исходной мебели остаётся ограничением.

```sh
npm run render:preview -- --headless --view interior --room living --look photoreal
npm run render:quality -- --headless --view interior --room bathroom --look photoreal
```

`--look review` сохраняет обзорный свет старого CLI. На Mac Cycles использует
Metal, не MPS. `auto` допускает CPU; `gpu` выдаёт ошибку, если GPU недоступен.

### Отдельный конвейер изображений дизайна

Откройте `/?walk`, чтобы сразу войти в гостиную. Стрелки рядом с названием
концепции переключают интерьер квартиры с текущего ракурса. Когда сцена
в фокусе, `[` и `]` переключают концепции, а WASD двигают камеру. Меню
показывает реализованный проект и приём, который адаптирован для квартиры.

Во вкладке «Варианты дизайна» можно открыть концепцию в 3D или сравнить
кадры Cycles из выбранной комнаты. Десять новых концепций используют одну
модель для прогулки и рендера, поэтому в гостиной видна кухня в том же стиле.
Текущий проект (`current`) служит опорным кадром. Прежние концепции и палитры
доступны в меню сравнения.

Контуры, проёмы, высоты, инженерные объекты и позиции основной мебели сохраняются.
Декоративные панели — новые объекты предложения, а не перенос реальных стен.
Подтверждённый санузел защищён: для него доступен только текущий вариант.

```sh
# Реальные изображения Cycles, без браузера и внешнего API:
npm run design:images -- --room living --variants current,birch-steel,olive-cherry,clay-arch --preset preview
# Только схемы и задания для разработки визуальных концепций:
npm run design:prepare -- --room bedroom
```

Каждая серия сохраняет независимый снимок исходной модели и решений, варианты
JSON, план, маркировку комнаты, развёртки, задание `prompt.txt`, экспорт GLB,
PNG и `manifest.json` с SHA-256, перечнем изменений и проверкой геометрии.
Сохранность архитектуры проверяется отдельно: геометрия предложенной мебели,
панелей и светильников намеренно отличается от текущего проекта. Blender
проверяет импорт именно выбранного варианта. Готовые кадры сохраняются
при отмене. Исходный проект и документы не перезаписываются.
По умолчанию выбран быстрый `draft` для сравнения концепций; для фактуры и деталей
используйте `preview`, для финальных изображений — `quality` или `ultra`.

Для AI-концепции передайте генератору изображений `render.png`, схемы и
`prompt.txt` из папки варианта. Полученное изображение можно добавить отдельно:

```sh
npm run design:images -- --import-concept /absolute/path/concept.png \
  --job exports/design-images/JOB_UUID --variant loft
```

Галерея отмечает AI-концепцию как изображение с непроверенной геометрией,
сохраняя исходный Cycles-кадр рядом. Генератор AI не встроен в локальный сервер:
эта стадия выполняется выбранным инструментом отдельно. Изображения, видео,
GLB и другие тяжёлые результаты остаются локальными и не публикуются в Git.

### Обновлённый рендер

FAST: зеркальные отражения сцены, контактное затенение SSAO, сглаживание MSAA и единый tone mapping. Камера подбирает масштаб под экран; полноэкранный просмотр доступен отдельной кнопкой. Когда камера и сцена неподвижны, тяжёлые проходы повторно не выполняются. В интерьерном виде внутренние двери открыты в презентационной копии модели; стены и потолки сохраняются, исходная модель не изменяется. Керамика имеет настоящую полость, мебель — скругления и отдельные фасады. Размеры комнаты по-прежнему условные.

PERFECT: мягкие студийные источники для обзора материалов, Cycles с denoising, AgX, 16-bit PNG для quality/ultra. Для экспорта без браузера и сервера:

```sh
npm run export:headless
npm run render:quality -- --headless
npm run render:quality -- --headless --view interior --lighting clean
npm run render:preview -- --headless --view interior --lighting evening --output exports/evening
```

`--headless` использует те же фабрики, UV и процедурные пиксели, затем встраивает PNG в GLB. Файловые текстуры должны быть загружены локально (`npm run textures:fetch`) и также встраиваются в GLB. Геометрию проверяет импорт Blender до рендера; headless export сам по себе не заявляет пройденную обратную загрузку. `--lighting day|clean|evening` доступен обоим экспортерам. `--reuse` сохраняет камеру и свет из существующей metadata.

Для последовательной проверки всех помещений с прогрессом и дополнительными обратными ракурсами:

```sh
npm run render:review -- --output exports/room-review
npm run render:review -- --preset quality --rooms living,bathroom-reverse --output exports/room-review-quality
```

Команда фиксирует одну исходную модель для всей серии, рендерит камеры внутри помещений на высоте 1600 мм и проверяет PNG, ревизию и импорт геометрии. Прогресс и результаты записываются в `index.json`, подробности — в каталог каждого ракурса. Тяжёлые изображения и GLB остаются в `exports/` и не включаются в Git по умолчанию. Разбор расстановки и ограничений: [проверка от 21.11.2026](docs/ROOM_REVIEW_2026-11-21.md).

## Исходная квартира

Площади проверены в присланном отдельном PDF: квартира 45,99 м²; санузел 4,44 м²; спальня 13,48 м²; гостиная 16,12 м²; кухня-ниша 6,22 м²; коридор 4,18 м²; лоджия 3,10 м² с учётной площадью 1,55 м².

Ревизия 6 восстанавливает контуры со стр. 2 присланного PDF: вытянутая квартира, боковой вход, спальня с лоджией, открытая кухня-ниша. Масштаб снят с **оконного проёма 2,4 м**, не с площади комнат. Размеры приближённые; это не обмер. [Метод и отклонения площадей](docs/SOURCE_GEOMETRY_AUDIT.md).

`npm run generate:apartment` собирает явно оцифрованную архитектуру (`source-plan.ts`) и отдельно создаёт предложение интерьера (`interior-preset.ts`). `applyGeneratedInteriors` сохраняет архитектуру и проверяет размещение внутри контуров. Санузел A3/M1/T1/Д2 сохранён с адаптированными привязками; остальные мебель, отделка и свет — предложения.

В просмотре, FAST PNG и Blender PNG указаны автоматическая генерация интерьера и приближённый масштаб. Метаданные содержат SHA-256 и страницу исходника. Ревизия 4 отозвана; ревизия 5 была временным состоянием только с санузлом. [Актуальный общий рендер](design/source-plan-v02/render.png).

Все виды: `npm run render:preview -- --headless --room all`; отдельная комната: `--room bedroom --view interior`. Полная модель не означает готовность к строительству или закупкам.

## Смета и документы

Вкладка «Смета и документы» содержит редактируемые цены в ₸, объёмы,
запас материалов, упаковки, финансовый резерв, источники и даты предложений.
Работы считаются без материального запаса. Неизвестные значения остаются пустыми;
явно заданный ноль отличается от отсутствия цены. Можно добавлять позиции,
исключать строки, сохранять CSV для Excel и переносимый JSON-черновик.
Черновик сохраняется отдельно от геометрии в браузере; несовпадающая ревизия
модели или решений блокирует его автоматическое применение.

Состав сопоставлен с [перечнем Земстандарта](https://земстандарт.рф/sheets)
21.11.2026: 29 технических и 3 вспомогательных типа документов. В «Составе
комплекта» показаны состояние каждого раздела, связанные листы и недостающие
данные; доступны поиск и фильтр. Контроль качества и сопровождение студии —
услуги, а не автоматически выполненные работы.

Комплект включает общие планы, маркировку углов и развёртки всех помещений,
полы и отделку, ведомости проёмов, кухни, мебели, декора и потолочного оборудования,
размещение сантехники, электроточки и связи выключателей со светом. Геометрия
и количества берутся из общей модели; неизвестные схемы демонтажа, конструктивные
узлы, отопление, климат и электроснабжение оформлены как задания с открытыми
исходными данными. Текущая смета охватывает только санузел. Бойлер, тёплый пол
санузла и ночная подсветка не возвращаются в комплектацию.
Это предварительный выпуск, а не утверждённый рабочий проект: реальные обмеры,
инженерные привязки и предложения поставщиков ещё нужны.

```sh
npm run documents:generate
npm run documents:generate -- --draft /absolute/path/estimate.json --out exports/quoted
npm run documents:pdf                    # macOS + Swift / AppKit
npm run documents:pdf -- --draft /absolute/path/estimate.json --out exports/quoted
```

Результат по умолчанию в `exports/documents/`: автономный `documents.html`,
`estimate.csv`, `estimate-draft.json`, структурированный `dossier.json`,
`manifest.json`, реестр `studio-coverage.json` и векторные схемы `drawings/*.svg`.
Команда `documents:pdf` также создаёт `documents.pdf`, PNG страниц для проверки
и соответствие ID листов физическим страницам `qa/page-map.json`.
На Windows/Linux откройте HTML и выберите печать в PDF. Кнопка «Печать / PDF»
в приложении печатает текущий расчёт, включая введённые цены.
Нативный PDF требует совместимых Swift и macOS SDK. При ошибках SDK используйте
печатный HTML; это тот же комплект.
Для просмотра без сервера: `npm run preview:offline`, затем открыть
`.artifacts/offline/home-design-preview.html`.

## Проверки

```sh
npm run test:core       # Без сторонних зависимостей: единицы, полигоны, проёмы, JSON, runner
```

## Видеотур: прогулка внутри

Вкладка «Видеотур» локального приложения запускает Blender и показывает прогресс, число сохранённых кадров, время, ETA, устройство, паузу и продолжение. По умолчанию: 60 секунд, 24 FPS, 960 × 540. Для спокойной прогулки используйте 60–90 секунд; короткие варианты — ускоренная проверка всего маршрута.

```bash
npm run tour -- --device gpu --seconds 60 --background --output exports/walkthrough
open exports/walkthrough/progress.html
# Пауза после текущего кадра:
npm run tour:pause -- --output exports/walkthrough
# Продолжение с теми же моделью, кодом и настройками:
npm run tour -- --resume --background --output exports/walkthrough
```

`gpu` использует Metal на Apple Silicon и явно завершает запуск с ошибкой, если GPU недоступен. `auto` разрешает CPU fallback. Нужны установленный Blender, FFmpeg и FFprobe; нестандартные пути задаются `BLENDER_PATH`, `FFMPEG_PATH`, `FFPROBE_PATH`. Если Metal недоступен из ограниченной среды агента, запускайте эту команду в обычном Terminal/iTerm2. Исходный рендер не перезаписывается: после изменения кода или модели выберите новый каталог.

Камера движется непрерывно на высоте 1,6 м: коридор → санузел → спальня → лоджия → обратно через коридор → кухня → гостиная. Маршрут около 25 м, с плавными поворотами и остановками для осмотра. Планировщик ищет проход по контурам полов и реальным дверным проёмам, избегает мебели и стен с запасом 140 мм; плотная проверка маршрута и каждого кадра выполняется до Blender. Это проверка пути камеры в эскизной модели, не заключение об удобстве реального прохода.

В кадре всегда остаётся вся квартира: стены, потолки, соседние помещения, розетки и светильники. Межкомнатные двери открываются только в отдельной презентационной копии JSON; эта копия проходит через обычные канонические фабрики и проверку GLB. Архитектура в Blender не перестраивается. Исходный проект сохраняет свои дверные положения. Та же полнота окружающей сцены применяется к отдельным видам «Внутри». Сгенерированный интерьер и необходимость обмера отмечены в видео. Рендеры и видео не добавляются в git по умолчанию.


### Санузел: смета и фотографии материалов

Рабочая оценка от 15.11.2026 находится в `src/data/bathroom-budget.json` и автоматически открывается в «Смета и документы». 47 позиций, материалы и работы, обязательный гигиенический душ, резерв 15%, график 6–7 недель. Карточки поставщиков находятся на вкладке «Материалы и поставщики». Это оценка до обмеров и предложений подрядчиков, не заказ.

`public/textures/laparet-noa/sources.json` фиксирует оригинальные фотографии двух артикулов и контрольные суммы. Команды `npm run dev`, `npm test` и `npm run build` автоматически восстанавливают отсутствующие фотографии через `textures:fetch`; существующие файлы с совпадающим SHA-256 не скачиваются повторно. Перед отдельным headless-экспортом после чистого клонирования выполните `npm run textures:fetch`. CI использует тот же `pretest`, поэтому JPG не требуется хранить в Git. Фотографии встраиваются в GLB обоими экспортерами; API рендера и Blender не требуют доступа к магазину. Дуб — процедурный до выбора мебельного декора. Права на исходные фото остаются у владельца; открытая лицензия не предполагается.

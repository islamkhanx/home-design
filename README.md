# Home Design

Локальный параметрический просмотр квартиры: Vue 3 + TresJS / Three.js для FAST, GLB → Blender Cycles для PERFECT. Один JSON, одна геометрия, два способа показа.

**Текущая версия — read-only просмотр.** В интерфейсе доступны ракурсы, размеры и сценарии света. Модель редактируется только в исходном JSON/TypeScript. `npm run build` и тесты проходят. Результаты проверок приложения и отдельных дизайн-исследований: см. [протокол](docs/VALIDATION.md).

## Контекст и выбранный дизайн

[Общий контекст проекта](docs/PROJECT_CONTEXT.md) · [Спецификация санузла](docs/bathroom-spec.json) · [Галерея схем и рендеров](design/README.md).

Текущий выбор: **A3 / M1 / T1 / У1 / Д2**, ванна, подвесная сантехника и электрический полотенцесушитель. Ночная подсветка исключена. Интерактивная модель синхронизирована по A3 / M1 / T1 / Д2. Деталировка У1 и размещение полотенцесушителя остаются открытыми; актуальность определяется спецификацией.

## Запуск

Нужны Node.js 22.16+, npm, браузер с WebGL2. Для PERFECT — установленный Blender с Cycles (целевые версии 4.5 LTS / 5.x; фактическая совместимость проверяется полным тестом).

```sh
cd home-design
npm install
npm run dev
```

Открыть `http://127.0.0.1:5173`. Для CLI-экспорта используется установленный Google Chrome на macOS либо Chromium Playwright:

```sh
npx playwright install chromium
cp .env.example .env
npm run doctor
```

В `.env` можно задать `BLENDER_PATH`, `CYCLES_DEVICE=auto|cpu|gpu`, `CHROME_PATH`. Для стандартной установки Blender на macOS путь находится автоматически. `gpu` требует рабочий GPU; `auto` пробует GPU и допускает переход на CPU.

## Просмотр дизайна

- «Общий вид», «Внутри» и «План»; мышью можно вращать, приближать и перемещать камеру.
- Размеры включаются отдельно; по умолчанию подписи не перекрывают интерьер.
- «Материалы» — нейтральный обзорный свет. «Основной» — предложение G1/G2; «Вечер» — только приглушённое зеркало. Ночной сценарий исключён.
- Световые потоки в модели сохранены; яркость FAST нормализована для показа на экране. Это не расчёт lux.
- Фактура дерева и камня имеет метрический масштаб, карты шероховатости и микрорельефа. Текстуры — условные образцы, не каталожная отделка.
- Нет редактирования, выделения предметов, дерева объектов, добавления/удаления, импорта/экспорта и панели Blender. Старый localStorage редактора не читается и не перезаписывается.

Для автономного HTML, который можно открыть без dev-сервера:

```sh
npm run preview:offline
```

Открыть `.artifacts/offline/home-design-preview.html` обычным браузером. Скрипт включает приложение, стили и процедурные материалы в один файл. При использовании собственных файловых текстур автономную упаковку нужно дополнить ими.

## CLI: экспорт и финальные изображения

```sh
npm run export:scene
npm run render:preview
npm run render:quality
npm run render:ultra

# Своя версия исходного JSON:
npm run export:scene -- --input /absolute/path/apartment.json --view plan
npm run render:quality -- --input /absolute/path/apartment.json --view interior --device cpu
```

`export:scene` запускает собственный временный Vite и headless-браузер, использует **тот же** экспортер, сохраняет `exports/latest/{scene.glb,scene.metadata.json,apartment.json,fast.png}`. `render:*` по умолчанию делает свежий экспорт, затем рендерит в `exports/<preset>/render.png`. `--reuse` явно разрешает использовать уже существующий экспорт в соответствующем каталоге. CLI не читает localStorage вашего обычного браузера.

| Preset  |       PNG | Максимум samples | Adaptive threshold |
| ------- | --------: | ---------------: | -----------------: |
| preview |   960×540 |               32 |               0.08 |
| quality | 1920×1080 |              256 |               0.02 |
| ultra   | 3840×2160 |             1024 |              0.008 |

Все режимы используют denoising. Время зависит от сцены и компьютера. Проверка `geometry-validation.json` должна пройти до рендера; `render-report.json` фиксирует устройство, preset и исходную ревизию.

Blender запускается через CLI. Локальный runner сохранён для автоматизации; в пользовательском интерфейсе его элементов нет. `npm run build` создаёт статический FAST-просмотр; `npm run preview` не запускает процессы Blender. Сервер не требует аккаунта, не отправляет сцену в облако, не принимает произвольные команды или пути выполнения. Переданная GLB должна содержать текстуры и буферы внутри файла.

### Обновлённый рендер

FAST: зеркальные отражения сцены, контактное затенение SSAO, сглаживание MSAA и единый tone mapping. Камера подбирает масштаб под экран; полноэкранный просмотр доступен отдельной кнопкой. Когда камера и сцена неподвижны, тяжёлые проходы повторно не выполняются. В интерьерном презентационном виде дверь скрыта, чтобы не заслонять камеру; её геометрия остаётся в канонической модели. Керамика имеет настоящую полость, мебель — скругления и отдельные фасады. Размеры комнаты по-прежнему условные.

PERFECT: мягкие студийные источники для обзора материалов, Cycles с denoising, AgX, 16-bit PNG для quality/ultra. Для экспорта без браузера и сервера:

```sh
npm run export:headless
npm run render:quality -- --headless
npm run render:quality -- --headless --view interior --lighting clean
npm run render:preview -- --headless --view interior --lighting evening --output exports/evening
```

`--headless` использует те же фабрики, UV и процедурные пиксели, затем встраивает PNG в GLB. Внешние файловые текстуры требуют обычного browser export. Геометрию проверяет импорт Blender до рендера; headless export сам по себе не заявляет пройденную обратную загрузку. `--lighting day|clean|evening` доступен обоим экспортерам. `--reuse` сохраняет камеру и свет из существующей metadata.

## Исходная квартира

Подтверждены площади на плане: квартира 45,99 м²; санузел 4,44 м²; спальня 13,48 м²; гостиная 16,12 м²; кухня-ниша 6,22 м²; коридор 4,18 м²; лоджия 3,10 м² с учётной площадью 1,55 м².

В стартовой модели **только санузел**, условно 1800×2470×2700 мм. Эти числа не являются обмерами и дают модельную площадь 4,446 м². Все предметы имеют `evidence: assumed`. Другие помещения сохранены в данных с подтверждёнными площадями, но без выдуманной 3D-геометрии и не выводятся в просмотре. Они добавляются после получения размеров. Проект не является монтажным чертежом.

## Проверки

```sh
npm run test:core       # Без сторонних зависимостей: единицы, полигоны, проёмы, JSON, runner
npm test               # Также реальная Three.js геометрия и габариты компонентов
npm run build          # Vue/TypeScript + production bundle
npm run test:e2e        # Реальный браузер: read-only UI, камеры, свет, GLB и PNG
npm run test:e2e -- --blender  # Дополнительно импорт и Cycles preview, сверка геометрии
```

CI повторяет полный маршрут с CPU Blender. Зелёный статус CI не заявляется до фактического запуска. Зависимости закреплены в `package-lock.json`; для воспроизводимой установки используйте `npm ci`.

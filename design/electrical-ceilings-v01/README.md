# Розетки и потолки · ревизия 7

Общая геометрия квартиры сохранена по исходному плану ревизии 6. Добавлены 18 розеточных блоков (30 гнёзд) и 5 выключателей. Это автоматически созданное предложение, не монтажный электропроект. Привязки заданы к стенам канонической модели и не пересекают проёмы.

- `electrical-kitchen-render.png`: кухня без мебели для проверки точек; физические размеры механизмов сохранены.
- `ceiling-living-render.png`: потолок гостиной **снизу**; это не отражённый план потолка. Белая матовая поверхность на условной отметке 2850 мм.
- `E-*.svg`: планы точек по комнатам, количество механизмов и высота до центра.
- `C-*.svg`: схемы потолков и света по комнатам.
- `electrical-kitchen-plan.png`: проверенный растровый просмотр схемы кухни.

В приложении используйте «Электрика» и «Потолки». В обычном интерьере потолок виден; в разрезном общем виде скрыт для просмотра мебели. Подписи точек показаны в интерактивном режиме электрики и на SVG, физические модели экспортируются в Blender без изменения геометрии.

Санузел: две розетки у тумбы и одна для стиральной машины; выключатель снаружи. Ночная подсветка не добавлена. Полотенцесушитель, подключение варочной панели, инженерные потребители, трассы и защита остаются на согласовании.

Воспроизведение:

```sh
npm run generate:apartment
npm run documents:generate
npm run render:quality -- --headless --device cpu --room kitchen --view electrical --output exports/electrical-kitchen
npm run render:quality -- --headless --device cpu --room living --view ceiling --output exports/ceiling-living
npm run preview:offline
```

Проверено: 52 теста, production build, два Cycles-рендера 1920×1080. Каждый импорт: 521 mesh-часть, максимальная ошибка границ 0.000000954 м. Браузерный E2E не подтверждён: среда блокирует сервер `127.0.0.1:5173` с `listen EPERM`.

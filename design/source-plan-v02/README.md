# Вся квартира по исходному плану · ревизия 6

`render.png` — Blender Cycles, 1920 × 1080. Интерьер предложен автоматически внутри контура, оцифрованного со страницы 2 присланного PDF. Масштаб — окно 2400 мм / 204 px; площади помещений не задают длины стен. Это приближённый эскиз, не обмер и не монтажный проект.

Сохранены вытянутая форма, боковой вход, лоджия за спальней, открытая кухня-ниша и выбранная композиция санузла A3/M1/T1/Д2. Линейные размеры, проходы, инженерия, чистовая высота и мебель требуют проверки. Высота оболочки 3000 мм — условная нижняя граница по договору; потолок 2850 мм — предложение.

На изображение нанесена отметка автоматического интерьера и масштаба по окну. [Метод восстановления и отклонения площадей](../../docs/SOURCE_GEOMETRY_AUDIT.md).

Воспроизведение:

```sh
npm run generate:apartment
npm run render:quality -- --headless --device cpu --output exports/source-plan-quality
```

Отчёты подтверждают идентичность геометрии при импорте в Blender, не точность строительных размеров.
